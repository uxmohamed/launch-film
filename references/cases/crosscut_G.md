# Crosscut G: ChatGPT Work, t0.ai, Microsoft Copilot

All three are **~100 s AI-assistant launches**: ChatGPT Work 100 s, t0.ai 105 s, Copilot 96 s. All are longer than the manual's 60–95 s launch band. All three sell an agent that works across your tools, and they solve the same problem three different ways:
- ChatGPT Work: a faithful product walk-through with typed chapter cards;
- t0.ai: a kinetic-type argument with the UI deferred to the last third;
- Copilot: a designer's manifesto in which the UI is constructed on screen.

## Recurring patterns
1. **The prompt is the hero object.** Each film returns to one input field 5–8 times:
   - ChatGPT: #20, #32, #84, #104, #130, #153;
   - t0: #25–41, #165, #169;
   - Copilot: #48–60, #76–82, #94, #128.

   The prompt text itself is the demo's script: real, specific, and typed at a readable 12–15 chars per 0.5 s.
2. **Slot reel inside the input.** The same card and position with the query swapped:
   - t0 "code" → "content" (#31→#34);
   - Copilot "Research" → "Analyze…" → "Visualize…" (#54–57).

   The manual's slot reel has migrated from type-on-ground into a UI field.
3. **Italic, colour or weight marks one word per line.** ChatGPT uses a colour ("Work"), Copilot an italic serif ("*you*"), t0 a green underline or X. Each film uses exactly one marking system everywhere.
4. **The newest word or label enters in a transient state and settles in one frame (0.5 s):**
   - ChatGPT: green/red → blue;
   - t0: labels green → black, "run" grey → black;
   - Copilot: an italic gradient wipe.

   This confirms the manual's arrival state, but all three are *colour/tone* arrivals, not blur.
5. **Vertical echo stack of one word:** t0 "Scaling" ×5 (#12–16) and Copilot "when" ×6 (#72–73). Both hold 1–1.5 s and resolve to a single line. This is a new shared device.
6. **Clarifying-question UI** (an agent asks before acting): Copilot "Who is the audience?" (#62–63), t0 "What basis should the 12-month projection use?" (#173–177). The films sell *judgement*, not speed.
7. **Receipts and provenance micro-copy:** "Worked for 2m 30s" (ChatGPT), "Referencing memory" (Copilot), "Permissions: Ask for approval" (ChatGPT), "Monitoring" (ChatGPT). Trust cues are placed where the eye lands.
8. **Ending by typed type, then logo.** All three end on type → logo, with the logo at ~3–5% of frame height:
   - ChatGPT: backspace → logo;
   - t0: scribble orbit → morph into the wordmark;
   - Copilot: gradient word reveal → squares converge.

   The logo holds are **1.5–2.5 s**.

## Contradictions between the three (and why)
- **When the product name lands:**
  - ChatGPT: 3.5 s (#7–12);
  - Copilot: the mark at 8 s (#16), the name at 89 s (#178);
  - t0: 55 s (#109, 52% of runtime).

  t0 can delay because it has no brand equity, so it has to earn attention with the problem first. ChatGPT has equity, so the name is the hook.
- **UI fidelity:** ChatGPT shows near-real full windows for ~30 s in total. Copilot rebuilds and deconstructs everything. t0 hides the UI until 76% of the runtime. The more famous the product, the more literal the UI.
- **Camera:** ChatGPT is locked ~85% of the time. t0 is almost never still: it trucks word to word for 32 s (#42–108). Copilot is between them, with slow pushes.
- **Ground:**
  - ChatGPT: white void + a stock starfield wallpaper;
  - t0: semantic ground inversion (cream = aspiration, black = problem, green = product, white = solution);
  - Copilot: a photoreal lit room + spec-grid paper.
- **Type scale:**
  - t0 is huge by default (12–60% of frame height);
  - ChatGPT is constant at ~4.5%;
  - Copilot is small and light (3–4%) with one shout ("amplify" at ~25%).

## vs. the manual

### (a) Techniques NOT in the manual
1. **Marker annotation layer** (t0). A hand-drawn brush-stroke layer in one colour on top of rigid type and grid.
   - Draw a 1-frame nub, extend 1–2 frames, arrowhead last. Erase by reverse-draw.
   - Uses: arrow = camera lead, underline = emphasis, X = negation, circle = selection.
   - A second colour (pink) is used for "wrong" only.
   - The logo gets a 3-frame **boiling** scribble burst (redrawn each frame at 2 fps) (#113–115).
   - Distinct from the manual's "connective line": it's authorial commentary, not product behaviour.
2. **Match-cut ground inversion** (t0 #7→#8). The same word is repeated in the next shot at 1.2–1.5× the size on the inverted ground, with the annotation continuing. It's a chapter change mid-sentence with no melt.
3. **Semantic ground polarity** (t0). Grounds encode argument valence (cream = ambition, black = problem, green = product, white = answer), not just chapter. The manual's "chapter coding by ground" is about acts, not valence.
4. **Echo stack** (t0 #12–16, Copilot #72–73). A key word is duplicated into 4–6 vertically stacked rows, which are:
   - either offset or clipped at different x positions (t0);
   - or have one row struck through (Copilot).

   Surrounded by tiny labels, held 1.5–3 s, then resolved to one line.
5. **Status relay** (ChatGPT #54–62). A fixed slot with an icon hard-swap + a grey verb phrase. The text reveals and erases left→right through a ~15%-wide gradient mask, ~1.1 s per tool. It's a spinner replacement that also names integrations.
6. **Hue-cycling arrival** (ChatGPT #11–12, #25, #189–194). The accent word or cursor dot enters in a different transient hue each time (green, red, pink) for one frame, then settles to the single brand accent. It technically keeps "one accent at rest" while signalling breadth.
7. **Placeholder-as-thesis** (ChatGPT #20→#21). "Ask anything" → "Do anything" in one frame, the product repositioning delivered through the placeholder.
8. **Voice waveform as the line** (ChatGPT #32–47). The recording waveform is the connective trace the camera trucks along. It then collapses into a spinner, and the transcript types in the same container (voice → text lineage).
9. **Context-under-prompt layering** (ChatGPT #84, #104). The next prompt bar is overlaid on the cropped previous artifact, so continuity comes from layering, not a morph.
10. **Timeline-to-table line lineage** (t0 #71–87). A horizontal timeline rotates 90° and its ticks stretch into spreadsheet rows. A cell becomes the product ground (#106–109).
11. **Error flood** (t0 #100–104). A bad cell spawns neighbours in a plus pattern, and the grid saturates in 3 frames with a hot centre. It's the "problem climax", then collapses to one good cell.
12. **Construct-the-UI-from-the-logo** (Copilot #16–40): deboss tile → blueprint → icon on keyline → rail → menu → window → responsive width morph to phone.
13. **Redline / spec overlay beat** (Copilot #51–53). Blue padding and dimension annotations sit on a component for ~1.5 s before it's used. Craft becomes content.
14. **Light-patch typography + whiteout** (Copilot #2–15). Words live inside the sunbeam of a photoreal architectural render. Type opacity follows the exposure, and scenes change by overexposing to white.
15. **Card-embedded "Verb your noun" montage** (Copilot #154–172). Each artifact card carries its own headline ("Protect your time"). 1.5–2 s per card, a 1-frame 50% ghost cross-dissolve, ending in a depth cluster.
16. **Gradient italic word reveal** (Copilot #178–185). The roman words are hard-on. The italic key word wipes in left→right through a soft gradient over 1–1.5 s.
17. **Dot cursor** (Copilot). The cursor is a solid black dot and a "click" is a 1–2 frame dwell. The manual says the cursor should be labelled, coloured or an avatar; this is a fourth option, abstracted.
18. **Converge-to-mark** (Copilot #188–191). The logo primitives start scattered on a grid and slide into formation. It's the inverse of the manual's subtractive clear.
19. **Kerning collision** (t0 #121–123). Two words arrive touching ("AIaccountant") and letter-space apart over 1 s.

### (b) Contradictions with the manual
- **"Full window 1–3 times, ≤1.5–5 s".** ChatGPT shows 5 full-window passages (#63–78 at 8 s, #97–103, #126–129, #136–147 at 6 s), about 25 s in total. Copilot's doc edit runs 8.5 s (#101–117). A premium tier-1 brand can hold real UI long when the audience wants to *see the real product*.
- **"UI lives in a world, never a void".** ChatGPT's macro shots and type cards sit on pure white (#20–62, #112–125), and its windows sit on a stock starfield wallpaper, not a brand plate.
- **"Every boundary needs a carrier / no blank boundaries".** ChatGPT hard-cuts ~20 times between white type, white macro and starfield window with no object, atom or line carried (e.g. #47→#48, #62→#63, #96→#97). Continuity comes only from the *project thread* (the lamp).
- **"Show the verb, not before/after".** ChatGPT's key slide edit is a hard state swap from line chart to bar chart (#142→#143). Copilot's rewrite is a grey ghost dissolve (#112).
- **"Holds breathe".** ChatGPT's window and type holds are frozen for 2–8 s (#75–78, #17–19, #144–147); only #30–31 drifts.
- **"Type is small, 1.5–3.5%; one shout".** t0 runs at 12–60% of frame height almost the whole film, so there is no single shout. Emphasis instead comes from the marker layer and ground inversion. ChatGPT's cards run at ~4.5%.
- **"One type family + mono".** Copilot pairs a light grotesk with an italic display serif on purpose (the serif is the "human" voice).
- **"At most one accent active".** t0 runs green + pink at once (#57, #61) plus lavender halftone and blue chart bars. It's disciplined through semantics rather than scarcity.
- **"Front-load proof in long films (logo by 20–35%)".** t0 names the product at 52% (#109).
- **"Final card holds 2–5 s".** Copilot's Microsoft logo holds ~1.5 s (#191–193), t0 ~2 s. Both sit at or below the floor.
- **Runtime.** All three are 96–105 s, above the 60–95 s "launch" band. The manual's cadence tiers still hold, but the longest acts run 8–32 s (t0's problem truck is 32 s continuous).

### (c) Manual claims strongly confirmed
- **The film is a sentence** (t0 is the purest case in the library: 105 s, one sentence, with UI as clauses; Copilot's manifesto split across the runtime).
- **Word-append with live re-centring** (ChatGPT #7–13, t0 #116–120).
- **Keyword box → ground / dot grows into ground** (t0 #17–21 box → cream ground; #106–109 cell → green ground carrying the logo).
- **Word split insertion** (t0 #25 card into "with ___ AI", #67 "pre-AI" into "the ___ era").
- **Two-weight metadata** (ChatGPT "5.6 Sol **/ Extra High**" #26; Copilot bold verb + regular object).
- **Macro → context pull-back** (ChatGPT #31→#32, ~3×).
- **Micro-states demos skip:**
  - hover fill on "Open" (#119);
  - the empty card before the text (#164);
  - timer 0:00→0:01;
  - chip-before-typing tray (#22–23).
- **Replace spinners with texture** (the status relay; blur-to-sharp image generation).
- **Dim or blur the context** (Copilot model picker over a ~10 px blurred page, #64).
- **Three depth planes with blurred front and back** (Copilot #89, #173–176).
- **Device-frame rule** (ChatGPT uses a phone only for "even when you're away", #153–177, where the platform is the point).
- **Object lineage** (t0 timeline → rows → cell → ground → logo; Copilot logo → icon → rail → menu → window → phone).
- **Bookend** (ChatGPT logo → typed name / typed name → backspace → logo, a true palindrome).
- **Proof as texture** (t0's finance metric labels #13–16; ChatGPT's KPI band).
