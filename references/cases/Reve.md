# Reve (annotations): analysis (71 frames, ~35 s, 16:9)

## 1. One-line concept
A feature teaser for Reve's image editor: **draw or annotate on an image to edit it** (select a region, attach a reference, sketch a sun or moon, and the AI renders it). The spine is **real drawing tools → the tool UI → "annotations are here" → edit by marquee, reference image, doodle → the film's own title cards get edited → "or just draw" → Now on Reve.**

## 2. Visual world
- **Ground:** pure white (#FFFFFF) for the tools and toolbar, flat light grey (#F0F0F0) for the toolbar tray, and pure black for the type cards (#50–52, #60–71). The edited photos are full-bleed, bright commercial stock-style imagery: a woman's portrait, a snowy forest, a dusk campsite.
- **Type:** a neutral grotesk (Neue Haas-like), bold for the shouts ("Annotate", "Directly", "Spotlight" at ~22% of frame height) and medium for small copy ("or just" ~5%, "Now on Reve" ~5%). There are two special type treatments: (a) **"annotations" as a script word** rendered first as a live blue marker stroke (#23–25), then as **3D rainbow chrome** (#26), then **silver chrome** (#27); (b) the handwritten "draw" (#63–64) in a thin white pen line.
- **UI staging:** an iPadOS-style frosted tool palette (a pen with a blue tip, an eraser, a size slider, a colour wheel) redrawn as soft 3D icons. Edits happen as UI overlays on the photo: a dashed blue marquee, a "Add this beanie" chip, an image card with transform handles, a prompt pill "add this to the background". The UI is large and there are no windows.
- **Logo:** a small pixel/halftone **butterfly** mark (~8% of frame width) on black.

## 4. Transition inventory
- **Real → UI object match** (#7→10): photographed tools of different kinds all share one tip position, and the stylised UI pen takes over the same position. The physical category becomes the software tool.
- **Tray grows from behind** (#11→12) and **siblings rise in** (#14, #18–21): the palette is assembled piece by piece, like the manual's "construction" but for a toolbar.
- **Stroke-tracking macro → pull-back to the title** (#23–26): the camera rides the pen, then reveals the finished word as a 3D title.
- **Material swap on a hold** (#26→27): rainbow chrome becomes silver on the same word, the same geometry, in 1 frame.
- **Marquee rubber-band** (#28–30): the selection is drawn on camera, so it's the cause of the edit.
- **Chip slide-in = cause** (#32, #35): the instruction enters from the right edge before the result appears.
- **Blur-bloom generate** (#38→39→41): submit → the frame is flooded with a defocused version of the reference → focus resolves to the result. Blur is the "thinking" state, instead of a spinner.
- **Doodle → render** (#44→45, #48): a hand-drawn symbol is replaced by its photographic effect in 1 frame.
- **The product edits the film's own title cards** (#51→53 "Invert this graphic" inverts the card; #55→56 marquee + word swap; #58 grey → white "Spotlight"). The type cards are also demo canvases.
- **Write-on into logo** (#63–66): the handwritten "draw" hands off to "Now on Reve" and the butterfly.

## 5. Easy-to-miss details
- All 7 real tools have their tips at **exactly the same screen point**. The riffle is a centred-anchor cut on a *tip*.
- There are 2 frames of **pure white** (#8–9) between the real and UI tools: a deliberate beat of nothing.
- The UI pen is ~3× the width of the real tools, which is a scale jump that signals "now we're in the app".
- The slider knob moves (#18→19→20) as a secondary motion while the colour wheel pops.
- In the marquee edit, the **gaze change** (#30→31) is the only difference in the result. It's tiny, confident proof.
- The generate step uses **the reference's own content, defocused** as the transition, so the blur carries colour continuity from the input to the output.
- "Spotlight" performs itself: the ground brightens from grey to white only after the word appears (#57→58).
- "draw" is written *inside a dark rectangle*, which is a canvas region, so even the last word is an annotation.

## 6. Pacing curve
A 3.5 s tool riffle at 2/s → a 1 s white breath → a 5 s calm UI assembly → a 1.5 s stroke macro → a 1 s title → a 10 s edit demo in 1–2 s beats (marquee, beanie, reference + prompt, generate, sun, campfire/moon) → 5 s of kinetic title cards that are edited live → a 2.5 s "or just draw" → 3.5 s logo hold. It's short and has a dense middle. The ending subtracts to one small pixel logo on black.

## 7. What makes it premium
- The feature (annotation) is demonstrated in the film's own *editorial* layer: titles get inverted, spotlighted and hand-written. The viewer learns the product by watching the film edit itself.
- It starts from physical, tactile objects (real crayons and pens), grounding a software feature in a universal human act.
- The results are plausible (gaze, beanie, lighting, campfire) and each result gets ~1 s. That's generous enough to register, fast enough to feel effortless.

## 8. Reusable techniques
1. **Physical-to-UI tool match.** Riffle 5–7 photographed real-world objects at 0.5 s each, all anchored at one point. Hold 1 s of blank, then the stylised UI version rises into the same anchor at 2–3× scale.
2. **Toolbar assembly.** The hero tool is first, the tray grows from behind it, and siblings rise in 1 per 0.5 s with a spring. Then pull back until the full palette is ~65% of frame width.
3. **Blur-bloom generate.** On submit, cross to a heavily defocused (~40 px) and 1.2× zoomed version of the input or reference for 1 s, then focus-pull to the result. It replaces a loading state.
4. **Doodle → render.** A crude hand symbol (sun, moon) appears for 1 frame and is replaced by its photoreal effect with no transition. The doodle is the cause.
5. **Self-editing title cards.** Put a feature's UI (a chip, a marquee, a prompt) directly on the film's own kinetic type and let it change the type (invert, swap word, relight).
6. **Material flip on the title.** The same 3D script word swaps material (rainbow chrome → silver) in 1 frame to show variability without moving the camera.
