# Crosscut A — Adaline, Aside, Cosmos, Lovable

## Recurring patterns
1. **The film is one sentence.** All four distribute a single line of copy across the runtime, one word or phrase at a time, and drop demo shots between the words. Adaline ("the bottleneck / is no longer the agent / it's you"), Aside ("Aside / can do / sign in…"), Cosmos ("What if we had / more context ?"), Lovable ("Your app / their data / You build / with / connectors"). The type is the timeline. Demo shots are subordinate clauses.
2. **Slot-reel / word-swap for lists.** Aside #128–#131 ("can do ___"), Lovable #47–#50 ("their ___"), Adaline #119–#125 ("The ___ cases") and the E01–E20 odometer #135–#138. Every video shows a list by fixing the sentence frame and swapping one word, never with bullets. The neighbouring options sit at 25–40% opacity above and below.
3. **Macro-cropped UI, never the full window for long.** Full windows appear for ≤1.5 s (Aside #52–#54, Lovable #16–#18, Adaline trace card #129–#134). Most UI is a single component (input bar, chat bubble, sign-in card, caption block) floating on the brand background.
4. **A connective line carries the camera.** Adaline's dotted trace line, Aside's timeline rail with a blue dot, Lovable's glowing cable between icons. The line both motivates the transition and stands for the product (traces / agent steps / connectors).
5. **Circle-scale wipe to change the ground colour.** Adaline #87→#89 and #149→#151 (to green), Aside #107→#108 (to dark for the benchmark). Each time, a small dot or circle grows to cover the frame in ~4–10 frames, and the new colour marks a new act.
6. **Icons inline with type.** Aside (globe, key, lock, server inside sentences), Lovable (app icons orbiting "connectors", avatars beside "They"). Lovable and Adaline do the same with circular portraits and nodes. The product's icon set is used as punctuation.
7. **Cursor as actor.** Aside (drag to trash, click the eye), Lovable (the "Admin" multiplayer tag, avatar cursors), Cosmos (tap dot). The cursor never just points; each click or drag triggers the next state.
8. **Quiet endings.** None of the four ends on a logo slam. Adaline ends on the URL on a grid, Aside on "aside.com", Cosmos on a small static wordmark, Lovable on a flat logo. Final holds run 1–2.5 s.

## Contradictions (opposite choices)
- **Type size:** Adaline and Cosmos set tiny type (2–3.5% of frame height, whispering, gallery-label feel). Aside and Lovable set huge type (8–30%). Tiny type suits reflective or taste brands (Adaline's manifesto, Cosmos's curation). Huge type suits punchy, social-first launches.
- **Cuts vs. continuity:** Adaline and Aside's demo avoid cuts. Camera moves along lines, and circles and washes bridge scenes, so it reads as one take. Lovable is almost all hard cuts, with continuity carried by the moving aurora background. Cosmos uses hard cuts only in its 0.5 s image slideshow.
- **Colour:** Adaline and Cosmos keep to 1–2 muted hues. Lovable is saturated gradient everywhere. Aside is monochrome plus one accent blue. The accent only earns attention if the rest is neutral (Aside), and Lovable instead makes the gradient the environment.
- **Humans:** Adaline uses real live action (the founder), integrated via cream washes. Lovable uses avatar photos as data. Aside and Cosmos have no people. Aside personifies the rival AIs as icons instead.
- **Word reveal style:** Adaline goes from ghost grey to ink (no motion). Cosmos uses a ~4px baseline settle. Aside uses a typewriter plus a karaoke accent colour. Lovable uses oversize-settle (150%→100%) and hard cuts. All are per-word, and none use per-letter animation except Aside's typewriter moments.

## Numbers and ranges (at ~0.5 s per frame)
- **Word or phrase cadence:** 0.4–0.6 s per word in type sequences (all four). A full caption stays readable for 1.5–3 s (Adaline 2–3 s, Aside ~2 s, Lovable ~1 s per beat).
- **Late-word lag:** the last word of a phrase lands about 0.5 s after the rest (Adaline "data", Cosmos "cosmos.so").
- **Shot length:** type beats run 0.5–1.5 s. Demo steps run 1.5–3 s. The longest single shots are the Aside timeline scroll (~6 s), the Adaline radial ring (~6 s) and the Lovable sign-in loop (~4 s).
- **Push-ins:** 1.1× for holds on logos and titles, 1.4× for a feature detail (Lovable dashboard), and 3–6× for a "dive into the component" (Aside search bar ×3–4 at the open, subagent row ×4, icon ×6).
- **Circle wipes:** 4–10 frames, from ~0.3–0.6 to >1.5 frame width.
- **Oversize-settle:** 150–160% → 100% in 1–2 sampled frames (≈0.5–1 s).
- **Neighbour opacity in slot reels:** 25–40%. Ghost-word start opacity: ~30%.
- **Dim before exit:** the whole comp drops to 30–40% for ~0.5 s before a chapter change (Adaline #45, Aside #64 and #67).
- **Logo reveal position:** Aside at ~20 s of 88 (23%), Adaline at ~36 s of 94 (38%, after the founder's "it's you"), Lovable and Cosmos only at the end. Longer films introduce the brand early and then prove it. Short teasers save it for the end.
- **Final logo or URL hold:** 1–2.5 s.
- **DOF blur on background elements:** ~4–8px at 1080p (Adaline type wall, Lovable icon orbit).
