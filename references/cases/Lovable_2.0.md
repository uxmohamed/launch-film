# Lovable 2.0 — platform launch (159 sheet frames; source indices run to 161 ≈ 80 s)

Near-continuous sampling (few skips: #152 = 154). Timings = source index × 0.5 s. Compare with the earlier `Lovable.md` (connectors film): same brand world, very different structure.

## 1. One-line concept
Lovable (AI app/website builder) launches 2.0: collaboration, Edit-in-preview, publish to your own domains, and Dev Mode (edit code / GitHub). Spine is a manifesto sentence that runs the entire film between feature demos: "Today, less than 1% of the world knows how to code — but that's about to change. Meet Lovable. Start building websites, ideas — faster than ever before. Join other builders creating 51,976 new apps every day. … Now with collaboration … Edit in preview … Instantly share what you built with your own domains … Introducing /dev mode. Edit code right on the spot, or in GitHub. Now it's your turn. What are you building? Lovable. lovable.dev".

## 4. Transition inventory
- **Dot-field push/pull (#1–4)** — gradient spheres (the heart's colours) push in, then retreat to a grid; the centre sphere survives and appears as the inline globe icon (#5). Object carries over.
- **Scale shout → small line (#7→#8)**, braces entering to wrap the phrase (#9) — the code motif framing the thesis.
- **Word-per-cut on changing grounds (#19–25, #109–114)** — hard cuts on each word, the ground (black / gradient / cream) rotates; continuity by rhythm.
- **Whiteout bloom (#25→#26)** — the gradient's white core swells to fill the frame and "Join" rises out of it.
- **Number + growth line (#31–33)** — the line is a chart and a cursor path at once.
- **Push into letter (#36–38)** — "day" scales up until the counter of the "a" holds a sparkle, which is the next shot.
- **Prompt pill collapse → card (#50–55)** — manual's prompt → pill → result, but in reverse scale: the pill is a giant hero, pulls back, compresses to a thin bar, then expands into the app card inside the same aura. The aura is the carrier.
- **Macro dive to chat input (#57–59)** and pull-back to reveal result (#64–67).
- **Cursors fly from type into UI (#69–70 → #80–83)** — named cursor pills first appear as typography companions, then as multiplayer cursors on the dashboard.
- **Avatar row → toolbar stack (#76–79)** — faces shrink into the avatar stack beside Invite/Publish: people become UI.
- **Icon → button → toolbar pull-back (#86–90)** — reverse of "push to affordance": start on the icon at 50% frame, pull back 5× to reveal it's a button in the toolbar.
- **Depth-of-field selection (#94–100)** — background editor blurs when inspector opens.
- **Domain slot reel inside a modal (#117–121)**.
- **Browser → device pull-back (#122–126)** — URL bar → site → laptop in a real room.
- **Chapter text → toggle chip (#129→#130)** — "/dev mode" becomes the `<>` chip it names.
- **Gradient → heart (#145–151)** — the ground blob morphs into the heart logo shape; then the heart shrinks to the icon on black (#152). Bookend of the dot field.

## 5. Easy-to-miss details
- Glyph-scramble as the newest character: "cod#|" (#8), "/dev mo}" (#128), "Edit co}" (#139). The terminal glyph is a code symbol (`#`, `}`), not random noise — scramble is on-brand for "code".
- "creatin" (#29): letters sit at different baselines (c raised, t/i lowered) then settle — per-letter bounce arrival, ~1 frame offset.
- Ghost-arrival (grey + slightly lower) used for the last clause: "change" (#12), "the spot" (#141).
- The heart logo changes from the old flat heart (#15) to the new gradient heart (#17) mid-shot — the rebrand is itself a morph.
- The prompt pill's aura thickens and saturates as the pill shrinks (#50→#53) — the glow is inversely scaled to the object, keeping visual weight constant.
- Cursors in #69 are labelled "Lucy" and "Jonathan" — the same names later appear in the Invite modal (#74: Jonathan) and on the dashboard (#80–82). Names are continuous across shots.
- Invite modal: the invite list grows one row per press (Jodie + Noah → + Jonathan).
- In the Publish modal the domain changes 4× but the modal tilt drifts continuously (~5° → ~3°) — the reel runs over a moving object.
- "Maximize Results" gets a purple colour + selection highlight via a picker panel (#104–105) — the colour of the edit matches the brand gradient's violet.
- "day" push reveals a tiny pink sparkle inside the counter of the "a" at #37 one frame before the sparkle fills the frame (#38).
- The number ticker has **no** easing in the digits: 30,952 → 45,966 → 51,976 — decelerating deltas (15k, 6k) = expo-out in count.

## 6. Pacing curve
- 0–19 s: manifesto — the fastest passage (word-per-0.5 s cuts, 3 grounds, 4 shouts). Front-loaded energy; logo at ~8 s (10% of runtime).
- 19–23 s: output riffle (sites, laptop).
- 23–34 s: first long demo (prompt → app → sidebar), 1 s per beat, one camera move per beat.
- 34–42 s: collaboration chapter.
- 42–55 s: edit-in-preview — the longest single demo (~7.5 s), calmest.
- 55–63 s: share/publish (shouts "what"/"built" then domain reel).
- 63–72 s: /dev mode chapter on black.
- 72–80 s: ending — "Now it's your turn / What are you building?" on gradient that becomes a heart; logo; URL 2 s hold.
- Each chapter opens with a type card on a changed ground (cream = collab/edit, gradient = share, black = dev mode).

## 7. What makes it premium
- The product features are subordinate clauses in one continuous manifesto; chapter cards are part of the sentence ("Now with collaboration", "Edit in preview", "Instantly share what you built…").
- Every feature is shown through **one macro affordance** (Invite button, Edit button, Publish button, `<>` toggle) before the full UI — the button is the chapter's icon.
- The gradient isn't decoration: it's the aura around the prompt, the colour of the new heart, and the ground that becomes the heart at the end.
- Names of collaborators persist across 3 shots.
- Photographic device shots (rocks, desk with plant) give generated sites a "real world" presence exactly twice.

## 8. Reusable techniques
1. **Manifesto on rotating grounds.** One word/phrase per 0.5–1 s, cycle 3 grounds (cream/gradient/black); insert 3–5 scale shouts at 25–35% height on the key verbs. Chapter cards reuse the same system.
2. **Code-glyph scramble terminal.** While typing, the newest character is a code symbol (`#`, `}`) for 1 frame before resolving.
3. **Giant prompt pill with inverse aura.** Prompt box at ~60% frame width, gradient aura ~15% frame thick. As the camera pulls back 3× the aura saturates/thickens; after send the pill compresses to a thin bar (1 frame) and re-expands as the app card inside the aura.
4. **Icon-first pull-back.** Open on the feature icon at 40–50% frame height, pull back ~5× over 1.5 s to reveal it as a button in the real toolbar; cursor clicks it on arrival.
5. **Named cursors carried from type to UI.** Introduce collaborator cursors as labelled pills next to the chapter title; reuse the same names in modal lists and live cursors.
6. **People → UI shrink.** Row of 5 face circles at ~20% height shrinks ~4× into the app's avatar stack.
7. **Slot reel inside a modal.** Keep a tilted modal drifting; swap only the variable field (domain) every 0.5 s, cursor re-presses the CTA each time.
8. **Ground → logo shape ending.** The full-frame gradient blob slowly reshapes into the logo silhouette (heart) under the last line of copy (~3 s), then cut to the logo icon small on black.
