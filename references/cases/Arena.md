# Arena (LMArena) — brand identity / rebrand film (142 sheet frames; source indices run to 151 ≈ 75 s)

Note: de-duplicated sheet — labels `#n (source)`; source skips a few frames (e.g. #44 = 046, #58 = 062, #115 = 123). Timings use source index × 0.5 s.

## 1. One-line concept
Arena, the crowdsourced AI-model leaderboard (head-to-head "A is better / B is better" voting), unveils its new identity. Spine: **the identity is built on screen in the order a design system is specified** — logo construction → typefaces → colour → data-viz language → product use → leaderboard categories → logo. Copy is carried by the type specimens themselves: "Bookishly / Academic / Perfectly / Precise … Where AI meets the real world … The new frontier … Best models for Text / Code / Text to Image / Experts / And Much More … Arena." It's a brand-guidelines book animated, with the typing caret as the film's atom.

## 2. Visual world
- **Ground:** alternates between warm off-white paper (#F7F4EE-ish with faint paper fibre, #14–57, #71–78, #90–110, #131–142) and near-black charcoal (#232323, #1–3, #10–13, #60–70, #79–89, #112–130). Both carry 1 px hairline construction guides (baselines, x-height lines, cap lines, a central cross) at ~10–15% contrast.
- **Type:** two families shown as *the subject*: a bookish serif "Martina Plantijn" (Light / Light Italic) and a grotesk "Basel Grotesk" (Bold/Medium/Regular/Mono). Specimen words at huge size: "AaBb" / "BbCc" macro at ~70–90% of frame height (#18–22), specimen words ~20–25% (#23–43), headlines ~6–8% ("Where AI meets the real world" #53–58). Every specimen carries a small metadata row underneath (TYPEFACE / STYLES / GLYPH-SET PREVIEW) at ~1.2% height.
- **Atom:** the text caret — a thick vertical bar ~1/8 of an em wide, in **blue** (#2F8CFF) while typing, turning **red** (#E5484D) at the delete/retype moment (#24–25, #34–35), and green at "Best models for" (#118).
- **Logo:** an Ionic column, first as a 3D rendered marble column + wireframe engineering drawing (#5–12), reduced to a flat line-art glyph (#13–14), set before a serif "Arena" wordmark.
- **Colour system:** "Scholastic Primaries" — yellow #F2C200, green #3DB54A, teal #2BB3B1, blue #2A8CF0, red #EF5350 — plus a 9-step warm-grey ramp "Sandscale" (white → black). Primaries used as model identity colours (Gemini green, Grok white, GPT red, Claude yellow, Qwen blue, Kimi teal, #79–81).
- **Imagery:** real product outputs (generated images/videos, a 3D Stonehenge WebGL scene, code) displayed in the Arena "Option A / Option B" comparison UI (#99–111); a psychedelic painted brain image as a background texture (#48–51); a wireframe globe with pixel "ARENA" letter tiles (#52–58).

## 4. Transition inventory
- **Line split / barn-door (#2–4)** — a single hairline becomes the edge of an opening panel: the grid line is the first object.
- **Wireframe → render (#7→#8)** — construction becomes the finished object in place (identity-building metaphor).
- **Shrink to glyph (#10→#13)** — 3D column scales ~5× down while the render swaps to flat line-art — "photo → logo" object lineage.
- **Caret-follow macro → pull back (#18–23)** — camera rides the caret at 80% type size, then pulls out to the specimen card.
- **Backspace / select-all / style-toggle** — every specimen swap is caused by a text-editing verb: delete letters (red caret), select-all (inverse block), toggle italic. The transitions are *keyboard actions*.
- **Specimen → product card (#47→#48)** — the specimen word "Precise" shrinks into the title position of a real web page card: type system → product.
- **Highlight wipe + glyph scramble (#57→#58)** — yellow marker box wipes under "real world", then the first letters scramble into noise, dissolving into pixel blocks (#59).
- **Pixel scatter (#59)** into swatches (#60) — the pixel squares become the colour chips.
- **Swatch parallax & oversize title (#60–70)**.
- **Data → empty boxes (#77–78) → coloured outline squares on charcoal (#79)** — the CI boxes lose their numbers and become legend markers: object carries over across a ground flip.
- **Grid-cell dive (#86–89)** — manual's Firecrawl grid-cell dive but with a perspective tunnel of 4–5 nested rects.
- **Radar polygon morph with ground flip (#93→#94)** — model change = colour + ground change simultaneously.
- **Prompt text → chat pill (#98→#99)**.
- **Output wall collapse (#112–117)** — hundreds of results pull back and collapse to a single card outline, which becomes the leaderboard frame.
- **Keyword slot via retype + scramble (#118–130)**, ending with box → primaries stripe.
- **Caret alone → logo (#131–133)** — bookend: the atom that started specimens types the wordmark.

## 5. Easy-to-miss details
- **Caret colour is semantic:** blue = typing, red = about to delete (#24–25, #34–35), green = product/leaderboard (#118). The caret never blinks during typing; it only blinks when alone (#131–132).
- Typing isn't strictly per-letter: "Bookis" → "Bookishly" jumps 3 letters in one frame (#26→#27) — cadence ~6 letters/s, faster than reading.
- Specimen metadata rows update live: the "STYLES" list highlights the active style ("Mono" in blue, #41; glyph preview turns blue, #42) — the UI of a type specimen, animated.
- A page border (inner margin ~2% frame) appears at #35 — the film switches from "infinite paper" to "a page in a book" exactly when the family switches from serif to grotesk.
- "e" shown with bezier handles while "iS" stay filled (#44–46) — one letter is dissected, the rest are finished.
- In "Where AI meets the real world", the key words "real world" are set in *italic serif* against roman — italic as emphasis, plus a yellow marker highlight that wipes left→right in ~1 frame (#56→#57).
- The whole headline line slides left as new words arrive (#55→#57) so the newest word stays near centre-right: the line is re-framed, not re-centred.
- Scholastic Primaries title is italic serif and is revealed from the left behind the swatches (#63 "Sch" partially hidden by the grey swatch) — swatches occlude type (layered depth).
- CI chart numbers tick by 10–15 units per 0.5 s (1448→1462→1472), boxes carry ±10 whiskers; row colours match model identity colours used later.
- The grey prompt text "a woman by the sea" (#98) is lighter than the committed text — ghost-arrival state as autocomplete.
- "B is better" button fills green on click (#105) — the only green in the product segment, linking to "Best models for" green box.
- Leaderboard table is tilted ~10° in 3D and drifts diagonally up-left; the left column of text has a thin vertical rule (#118–130) — a quote/bar rule, editorial.
- "And Much More" box turns into a 5-colour primaries bar (#129–130) — the colour system returns as the last graphic before the logo.

## 6. Pacing curve
- 0–7 s: slow logo construction (blueprint → render → glyph → lockup). Quiet open with a single line on black.
- 7–25 s: type specimens at ~2.5 s each — rhythmic, keyboard-driven, the "reading" passage.
- 25–35 s: first acceleration: specimen → product card → headline → pixel scatter → swatches.
- 35–45 s: colour and data viz; the grid-cell dive (#86–89) is the one big camera move (~44–47 s).
- 45–60 s: product proof (A/B outputs, WebDev), then output-wall pull-back = density peak/climax (#112–116).
- 60–70 s: leaderboard slot reel, 1 s per keyword, accelerating into scramble.
- 70–75 s: long 4.5 s logo hold on paper; caret-first reveal. Ending subtracts to a single caret before the logo.

## 7. What makes it premium
- The identity is presented as a **live editor**: every element is typed, selected, deleted, toggled — the brand feels authored, not animated.
- It shows the system's *rules* (typeface names, styles, swatch names, CI whiskers) as readable content — design literacy is the flex.
- Real product outputs (not mock thumbnails) from actual model comparisons.
- Ground flips paper↔charcoal are tied to meaning: paper = the brand/reading, charcoal = data/the machine.
- Italic serif used for exactly the emotional words ("new", "real", "Scholastic Primaries").

## 8. Reusable techniques
1. **Specimen-as-copy.** Each typeface is demonstrated by typing a word that *describes the brand* ("Bookishly", "Academic", "Perfectly", "Precise"). ~2.5 s per word: type (1 s) → hold (0.5 s) → edit-verb exit (0.5 s: backspace with red caret, select-all inverse block, or italic toggle).
2. **Semantic caret colour.** Caret ~0.12 em wide; blue while typing, red one frame before deletions, accent-green for product. Blink only when idle.
3. **Blueprint → render → glyph logo build.** Wireframe with dimension leaders (1.5 s) → rendered 3D object in a framed box (1 s) → shrink ~5× on dark (1.5 s, ease-in) → swap to flat line glyph → wordmark typed beside it.
4. **Macro caret-follow.** Type at 70–90% frame height; camera trucks to keep caret at ~70% frame width; 2–3 s, then pull back 3× to reveal the specimen card with metadata.
5. **Data-to-marker hand-off across a ground flip.** Chart boxes drain their numbers (1 frame), become empty coloured squares, ground flips to dark, and the squares become legend markers for the next scene.
6. **Output wall collapse.** Dozens of real outputs in 3D at 4–5 depth layers; pull back ~5× over 2 s, then collapse the cluster to a single card outline (0.5 s) that becomes the next frame's container.
7. **Keyword slot with retype + scramble.** Fixed "Best models for" + keyword in an accent box; each keyword retyped with 1–2 frames of glyph scramble, ~1 s per keyword; final box converts to a multi-colour palette bar.
