# Film modes

The 59 reference films fall into six modes. The universal laws in SKILL.md §2 hold in every mode. Everything else (type size, continuity strategy, how UI is staged, when the brand appears, how long the end holds) changes by mode. Pick the mode first. Hybrids are common: take the continuity strategy from the primary mode and borrow devices from the secondary one.

Case files are in `cases/`. Frame references (#n) point to them.

---

## M1. Product launch / SaaS demo
**Films:** Adaline, Aside, Cloudflare, Cosmos, Firecrawl, Harvey, Layo, Lovable, Lovable 2.0, Merciv, Raindrop, Veryfront, Figr, Zaro, Shapes, Island, LaunchAnything, ChatGPT Work, Microsoft Copilot, t0.ai, Claude Cowork, Perplexity Computer, Aurel, Medium, Google AI Studio, Spellbook, Opera Air, Superpower (two-world), Frontify.

**When:** a software product or feature where the viewer must understand what the product does.

- **Spine:** a sentence split across the runtime. Demo shots are its clauses.
- **Continuity:** object lineage. Follow one object (a query, message, contract or prompt) through its life. When hard cuts are unavoidable, a project thread holds them together (ChatGPT's lamp line).
- **Type:** a whisper register, 1.2–3.5% of frame height (down to 1.2% for mono on an empty ground), with one scale shout or one whisper-inversion. Social-first cuts can run 7–10% of frame height.
- **UI:**
  - Rebuilt and macro-cropped at 2–4×, floating on the film's ground.
  - Full windows appear 1–3 times for at most 5 s each. Big-platform films (ChatGPT, Copilot, Google) can hold real windows 6–8 s *if one project threads them*.
  - Borrow third-party UI to show the problem.
  - Device frames only for someone else's platform, for a mobile-native product, or when the device's state carries story (lid, clock).
- **Pacing:** inhale/exhale every 8–10 s. The climax is a zoom-through, a pull-back or a variant flip.
- **Brand timing:**
  - long films (over 60 s) name the brand by 15–35%;
  - teasers name it at the end;
  - two-world films name it at the hinge (35–40%).
- **Ending:** clear the stage, then hold a small logo or URL (4–5% of frame height) for 2–5 s. Add 1.5 s of empty ground if you like.
- **Signature devices:**
  - caret-follow typing;
  - named cursors;
  - caption performs the feature;
  - prompt ritual;
  - status relay;
  - hot text;
  - slot reel;
  - push to affordance;
  - grid-cell dive;
  - morph chain;
  - dot grows into ground.

## M2. Creative tool / generative model
**Films:** Figma Draw, Figma Shaders, Affinity, OpenAI Images 2.0, Reve, Burp, Google Pics (hybrid with M1).

**When:** the product *makes things* (images, video, vectors, shaders). The output is the argument.

- **Spine:** a sentence (often set inside the outputs themselves), or a lock-up bookend.
- **Continuity:** **same subject, many treatments.** Fix a subject's position and scale and change its rendering every 0.5 s for 4–10 variants, ending on the canonical version. A fixed UI element (a mode pill, a prompt box) acts as the *semantic anchor* that causes each change.
- **Type:** multi-voice. Several typefaces are deliberate, because range is the claim. Words can be diegetic (set inside generated signs, mugs, neon) with no overlay captions. The product can process its own title (smear, halftone, re-render the name in a new brush every 0.5 s).
- **UI:**
  - The output is the ground. Full-bleed artwork with a floating UI panel on top.
  - Tools are always shown **mid-drag**: sliders scrubbing, values ticking with the effect.
  - The cursor hovering a picker *is* the cut.
- **Colour:** the ground takes its colour from the artwork and can change every shot. Only the UI accent stays constant.
- **Pacing:** the 0.5 s riffle is the *main body* (60–80% of runtime), with 2–4 s breathers on hero results.
- **Generate step:** a blur-bloom of the reference (~40 px, 1 s), then a focus pull; or a denoise with a *linear* percentage; or a still that simply starts moving (still → alive).
- **Brand timing:** a lock-up in the first 2 s ("Brand [thumbnail] Product"), then the same lock-up at the end with a different thumbnail.
- **Ending:** a 1.5–3 s hold. Ending on the output itself (poster → website) is allowed.
- **Signature devices:**
  - self-restyling title;
  - cascading effect-pill stack (count escalating 1 → 7+);
  - shape-shifting stage window;
  - self-editing title cards (the product's UI edits the film's own type);
  - doodle → render;
  - material flip.

## M3. Brand / identity / design-system film
**Films:** Netflix, Coca-Cola, Instagram Brand System, Uber Icon System, OpenAI Brand, Google Material 3, Walmart, Arena, Shopify, iCloud+ (brand-product hybrid).

**When:** launching an identity, typeface, icon system or design language. The type and marks *are* the product.

- **Spine:** a chant or anaphora ("More ___.", adjective lists) or a system tour.
- **Continuity:** **palette + tempo + mark.** Strict duotone colour pairs per chapter, a 0.5 s metronome, and the mark at a fixed centre across dozens of cuts (Walmart's Spark). A persistent HUD frame can make about 60 hard cuts read as pages of one guidelines document (OpenAI: corner ticks plus a chapter label at 0.6% of frame height).
- **Type:** large registers throughout, from 7–15% of frame height up to 35–60% super-shouts, and words wider than the frame, trucked across. Emphasis comes from **behaviour**:
  - a variable-width axis that breathes;
  - an ink/ground polarity flip on the key word;
  - a self-describing adjective (LIGHTER loses weight, FRIENDLIER bends into a smile);
  - outline → fill specimens;
  - lines set in the weight they name.

  Size alternation (whisper 5% ↔ shout 50%) with a final inversion.
- **UI:** components are *actors*. A real component moves the way it does in the product and pushes the previous content away (component-as-wipe: Material's pull-to-refresh, Uber's tab bar). Other devices:
  - press → iris;
  - a list scrolling under a fixed highlight;
  - a theme-swap reveal;
  - a sibling-coupled press.
- **Pacing:** 0.5 s per card for long stretches. Riffles show the mark placed in real-world contexts.
- **Brand timing:** the mark within 0–2 s (it *is* the subject), and again at the end.
- **Ending:** accumulate (an asset wall of every image in the film, a carousel) and then cut to a **big** lone mark (25–45% of frame height) on an emptied ground, held 1–3 s. Or converge scattered primitives into the mark.
- **Signature devices:**
  - atom → label → chain (Coca-Cola's swoosh);
  - logo as punctuation in marquee copy;
  - icons ↔ letters morph;
  - a localised line in 4 languages, then on a billboard;
  - echo-letter onomatopoeia;
  - a headline stack;
  - learn the vocabulary, then find it in context.

## M4. Manifesto / model announcement / essay
**Films:** Claude Keep thinking, Claude Fable 5, Claude Fable 5.1, Claude keynote intro, Index by Parallel, Apple has a plan, Wabi, Blueprint, Flashback.

**When:** there's no UI to demo (a model, a mission, a cultural moment, an event intro), or the brand wants to own an idea before it shows a feature.

- **Spine:** one sentence told patiently, or one motif (a word in 13 materials, a digit built from 40 media, one shape rhymed across cuts).
- **Continuity:** **motif-anchored montage.** Up to about 100 hard cuts with no followed object, held together by:
  - the motif at a consistent centre and scale;
  - a grade and grain pass across all sources;
  - an anchor shape (a digit, an eyepiece ring, a grid cluster);
  - shape rhymes (leaf veins → rivers → circuit traces);
  - a fixed type position while grounds flip (Apple).
- **Cause:** natural motion, not clicks. A bird takes off; a butterfly flies at the lens and wipes to the title; clouds occlude passenger type; a falling piano cuts to black, then the aftermath.
- **Type:** whisper to mid, 1.2–5% of frame height. Diegetic words (signage, screens, labels). Annotation layers act as a second voice:
  - a hand-lettered proofreader with a caret (^) insertion;
  - a pencil underline 0.5 s after the phrase lands;
  - hairline "reasoning" lines tracked to real motion.

  Text leaves by backspace.
- **Pacing:**
  - a hidden-subject hold ladder (holds shrinking ×0.8 per shot);
  - a constant 2/s riffle with zero camera motion;
  - a climax by *slowdown*, or by the first camera move after long stillness;
  - a black breath (2.5 s of black with grain) before a punchline.
- **Brand timing:** withheld until 67–96% of the runtime.
- **Ending:**
  - Long holds are allowed (up to about 13 s), with life from world elements leaving (butterflies departing one by one, a slow ~25 s camera tilt under screen-locked type).
  - The lock-up can sit over live footage.
  - An epilogue after the tagline is allowed.
  - Loops and palindromes (the opening shot repeated frame-exact).
- **Signature devices:**
  - instrument portal;
  - found-glyph riffle;
  - specimen flies at the lens;
  - caret-born mascot;
  - hinge-dot sentence (the atom at centre between the halves of each line);
  - iris-close on the verb;
  - gravity collapse;
  - typing-history cascade;
  - paper-feed end;
  - odometer dates;
  - screen-as-caption push.

## M5. Hardware / physical product
**Films:** New Mac mini, Herman Miller Gaming, Perplexity Computer (hybrid with M1), iCloud+ (device hero).

**When:** the product is an object, or software tied to a device.

- **Spine:** benefits as a sequence of transformations of one object.
- **Continuity:** the **product stays at the centre and changes costume.** Each benefit grows out of its body (arms → wheels → tentacles → rocket), escalating in complexity, with a 0.5 s reset to the bare product between costumes.
- **Staging:**
  - rim-lit silhouettes (the body at ~5% luminance, only the bevels lit, the highlight travelling around the edge for ~3 s instead of a push);
  - a light chain (perforation → bokeh → ribbon → coil tunnel);
  - a push through the device screen as the switch into software;
  - a spec as an **ingredient**: a physical chip lowered *into* the product, with a one-frame jolt.
- **Type:** heavy caps flush in a frame corner, a different corner per chapter, with a micro-text spec margin. Imperfect letter fills are allowed ("I NA URE", a space snapping open).
- **Brand timing:** late (90–95%).
- **Ending:** a material wipe (the world's own substance fills the frame, then parts), then a short hold (1–2 s).

## M6. Founder / documentary
**Films:** Conduit, Sphinx, Adaline (hybrid with M1).

**When:** trust or vision depends on the people behind it.

- **Spine:** the founder's spoken argument. It can open with a historical parable (5–6 captioned graphic beats, 30–35 s; only for films of 90 s or more).
- **Continuity:** the interview is the home base. Intercutting to it is fine. Integrate graphics *into* the frame:
  - a negative-space HUD (speaker in the left third);
  - big captions composited **behind the speaker's head** (12–15% of frame height, with letters hidden by the head, alternating sides);
  - cream washes;
  - the person introduced *through the atom* (a stipple dot cloud crossfading to footage).
- **Proof:** stats over the person, with an accumulating logo field; a slit-open testimonial card.
- **Brand timing:** 35–50%.
- **Ending:** a blur-melt into a gradient, URL → wordmark, a 2–4 s hold.

## Rule overrides at a glance
| Manual default (M1) | Override by mode |
|---|---|
| Tiny type, one shout | M3: big registers are the system. M2: multi-voice. M5: corner caps. Every mode keeps *one inversion*. |
| Follow one object that changes form | M2: one subject, many treatments. M4: motif-anchored montage. M5: the product in costumes. |
| Things become, they don't cut | M3/M4: hard cuts are fine with palette + tempo + anchor, or a fixed type position. |
| Rebuild the UI; 1–3 full windows | M2: the output is the ground. M3: components as actors. Big platforms: real windows with a project thread. Borrowed UI for the problem. |
| Device only for someone else's platform | Platform owners (Apple), mobile-native products, and devices whose state carries the story. |
| One accent colour | Two accents with fixed meanings; strict duotone pairs per chapter (M3); grounds from the artwork (M2). |
| Front-load the logo in long films | M4 and M5 withhold it (67–96%). M3 shows the mark immediately. |
| End hold 2–5 s, small mark | M3: big mark, 1–3 s. M4: up to 13 s. M5: 1–2 s. Short manifestos: 1–1.5 s with a bookend. |
| End by subtraction | Or accumulate → cut to the lone mark (M3). Or the output itself (M2). Or the lock-up over live footage (M4). |
| Counters decelerate | Process meters are linear. Totals decelerate or jump. Real-time tickers run as life. |
| Slot reel 0.8–1 s | 0.5 s when items are 1–3-word tags and the fixed frame has already been read. |
| Glitch / tilt / glow are cheap | Glitch once on the claim word, decaying in 2 frames. Tilt only on macros. A "generating" glow only as a colour bridge. |
